# Contributing to MTG Inventory & Pricing Prototype

Thank you for your interest in contributing to this project.

This is primarily a personal portfolio and development project, so contributions are welcome but may not be actively reviewed or incorporated.

## Suggestions and Bug Reports

If you find a bug or have an idea for an improvement, please open a GitHub issue with:

* A clear description of the issue or suggestion
* Steps to reproduce the issue, when applicable
* Relevant error messages or screenshots
* Any additional context that may help explain the problem

## Pull Requests

For code changes, please:

1. Keep changes focused on a specific issue or improvement.
2. Avoid committing local data files, generated executables, API keys, or other sensitive information.
3. Test changes before submitting a pull request.
4. Clearly describe what was changed and why.

Please do not include API keys, credentials, personal information, or local database files in commits.

## Development

The project currently consists of an Excel/VBA front end with Python services supporting local card data and pricing.

Changes should preserve the existing architecture unless the purpose of the change is to improve or replace part of that architecture.

## Code of Conduct

All contributors are expected to follow the project's [Code of Conduct](CODE_OF_CONDUCT.md).
